# GitEye Support

GitEye is a community-maintained open-source project. Support is provided on a best-effort basis; there is no guaranteed response time or service-level agreement.

## Before asking for help

1. Install the [latest release](https://github.com/alfkonee/giteye/releases/latest).
2. Search [existing issues](https://github.com/alfkonee/giteye/issues).
3. Confirm Git works for the repository from a terminal.
4. For GitHub features, confirm `gh auth status` succeeds.
5. Open **Settings → About → Copy app details** so your report includes the exact build and toolchain versions.

## Where to ask

- Reproducible defect: use the [bug report form](https://github.com/alfkonee/giteye/issues/new?template=bug_report.yml).
- Product idea: use the [feature request form](https://github.com/alfkonee/giteye/issues/new?template=feature_request.yml).
- Security vulnerability: follow [SECURITY.md](SECURITY.md); never disclose it in a public issue.
- Questions about contributing: read [CONTRIBUTING.md](CONTRIBUTING.md), then open a focused issue if the answer is not available.

Include reproduction steps, expected and actual behavior, and relevant screenshots or sanitized command-log output. Never post access tokens, credentials, private keys, confidential repository contents, or unredacted personal paths.
